# Analyzing Historical Stock/Revenue Data and Building a Dashboard

This repository contains the completed and fully executed final assignment for the IBM Data Science / Python for Data Science and AI project: **Analyzing Historical Stock/Revenue Data and Building a Dashboard**.

## Overview
As a Data Scientist/Analyst working for an investment firm, the objective is to extract historical stock prices and quarterly revenue data using `yfinance` and web scraping techniques (`BeautifulSoup` + `requests`), then visualize and compare stock prices against revenue using **Plotly**.

## Completed Exercises:
1. **Question 1**: Use `yfinance` to Extract Tesla Stock Data (`tesla_data.head()`)
2. **Question 2**: Use Webscraping to Extract Tesla Revenue Data (`tesla_revenue.tail()`)
3. **Question 3**: Use `yfinance` to Extract GameStop Stock Data (`gme_data.head()`)
4. **Question 4**: Use Webscraping to Extract GameStop Revenue Data (`gme_revenue.tail()`)
5. **Question 5**: Plot Tesla Stock and Revenue Dashboard (`make_graph`)
6. **Question 6**: Plot GameStop Stock and Revenue Dashboard (`make_graph`)
